# OOP Lab

C++ programs and sample outputs for OOP laboratory assignments.

## Structure

Each laboratory is kept in a separate folder. Each question has its own folder containing:
- `program.cpp`
- `output.txt`

Labs included:
- Lab-01: Basic programs
- Lab-02: Number, pattern, and array programs
- Lab-03: Functions, arrays, matrices, and employee programs
- Lab-04: Friend function programs, Constructors, copy constructor, and object pointer programs
- Lab-05: Single and multiple inheritance programs
- Lab-06: Multilevel, hierarchical, and hybrid inheritance programs
- Lab-07: Calendar for a given year; reverse a sentence using recursion.
- Lab-08: Store and display student details using a structure, including marks and CGPA.
